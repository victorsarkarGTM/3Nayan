# @3nayan/web

Public web app (Next.js): phone sign-in, onboarding, seeker home, practitioner application.

```bash
pnpm --filter @3nayan/web dev   # needs NEXT_PUBLIC_SUPABASE_URL / _ANON_KEY / NEXT_PUBLIC_FUNCTIONS_URL
pnpm --filter @3nayan/web e2e   # starts the functions dev server and Next.js itself
```
